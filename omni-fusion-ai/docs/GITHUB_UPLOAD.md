# Upload V7 to the existing repository

1. Extract the downloaded ZIP.
2. Open the repository on GitHub.
3. Open the existing `omni-fusion-ai` folder.
4. Choose **Add file → Upload files**.
5. Drag everything inside the new extracted `omni-fusion-ai` folder into the upload area.
6. Commit directly to `main`.
7. Open Vercel → Deployments and wait for the newest commit to show **Ready**.
8. Refresh the existing Vercel URL with `Ctrl + Shift + R`.

Do not create another Vercel project. Do not change the Root Directory or existing OpenRouter environment variables.
