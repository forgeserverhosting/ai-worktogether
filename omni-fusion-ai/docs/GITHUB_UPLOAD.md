# Five-step launch checklist

1. Extract the ZIP.
2. Create a private GitHub repository and upload everything **inside** the `omni-fusion-ai` folder.
3. Import that repository into Vercel with Framework Preset set to **Other**.
4. Add `OPENROUTER_API_KEY` and `OPENROUTER_MODEL=openrouter/free` in Vercel Environment Variables.
5. Deploy. Add additional provider keys later for a stronger and more reliable council.

Never paste an API key into GitHub files.
